АВТОНОМНЫЙ ПАКЕТ: ANTIGRAVITY MANAGER + МОСТ ДЛЯ CLAUDE
=============================================================

ПЕРВЫЙ ЗАПУСК (ОДИН РАЗ):
1. Включи свой привычный VPN на компьютере (например, Нидерланды или Германия).
2. Запусти файл `Настроить-Claude.exe` (или `Настроить-Claude.bat`) один раз:
   он автоматически настроит профиль Claude Desktop, почистит старые кэши и пропишет 1M контекст.
3. В окне Antigravity Manager на вкладке "Аккаунты" добавь свой Google-аккаунт
   и убедись, что тумблер включен (статус "1 / 1 Доступно").

ПОВСЕДНЕВНАЯ РАБОТА:
* Запускай `Запустить-Всё.exe` — он тихо в фоне поднимает Antigravity, мост (без черных окон консоли)
  и сразу открывает Claude Desktop.
* Или нажми `Включить-Автозагрузку.bat` — тогда всё будет само стартовать вместе с Windows.

ФАЙЛЫ В ПАПКЕ:
-------------------------------------------------------------
* `Настроить-Claude.exe`    — РАЗОВАЯ настройка профиля и моделей Claude (запускать 1 раз).
* `Запустить-Всё.exe`       — бесшумный лаунчер на каждый день (без лишних окон и консолей).
* `Antigravity-Manager.exe` — менеджер Google-аккаунтов.
* `claude-bridge.exe`       — фоновый мост (порт 8048, перенаправляет запросы и мапит 7 моделей).
* `Включить-Автозагрузку.bat` — добавить сервисы в автозагрузку Windows.
* `Выключить-Автозагрузку.bat`— убрать автозапуск из реестра Windows.
* `WebView2Loader.dll`      — системная библиотека интерфейса.
